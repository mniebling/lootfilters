# `lootfilters`

My ARPG loot filters and tooling to maintain them.

## Project Diablo 2

`pd2/loot.filter` is a minimal PD2 filter that preserves the normal item names while adding the socket count to socketed items on the ground, for example `[4]`.

To use it, copy it to `Diablo II\ProjectD2\filters\local`, select it in the PD2 launcher, and enable Loot Filter in the in-game PD2 options. After editing, reload with the configured hotkey (Numpad 0 by default).
