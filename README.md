# `lootfilters`

My ARPG loot filters and tooling to maintain them.

I typically prefer filters that are much more minimal than the "popular" ones.

## Project Diablo 2

`pd2/loot.filter` is a minimal PD2 filter. I try not to add too much visual noise to the dropped items, but do add some QoL like differentiating ethereal from socketed.

To use it, copy it to `Diablo II\ProjectD2\filters\local`, select it in the PD2 launcher, and enable Loot Filter in the in-game PD2 options. After editing, reload with the configured hotkey (Numpad 0 by default).
