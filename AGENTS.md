# Repository guidance

- Keep each game's files in its own directory (`pd2/`, etc.).
- Check `.agents/skills` for context on working with specific games' filters.
- Keep specialized syntax, workflows, and installation details in game-specific skills rather than duplicating them here.
- Make small, composable filter changes and preserve existing behavior unless requested otherwise.
- Add human-readable comments to rules.
- Do not modify a user's actual game installation unless explicitly asked.
- Update `README.md` when user-visible behavior or installation changes.
